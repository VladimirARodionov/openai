## 🔧 Настройка

### 1. **Переменные окружения**
Добавьте в ваш `.env` файл:

```env
# Улучшенная модель эмбеддингов
EMBEDDING_MODEL=text-embedding-3-large

# Настройки улучшенного поиска
USE_ADVANCED_CHUNKING=true
USE_QUERY_ENHANCEMENT=true
USE_METADATA_EXTRACTION=true
USE_HYDE=false
```

### 2. **Установка зависимостей**
```bash
pip install -r requirements.txt
```

### 3. **Проверка интеграции**
```bash
python test_integration.py
```

### **Семантический чанкинг**

### **Адаптивные параметры**
- Настройка поиска в зависимости от длины запроса

### **Обогащенные метаданные**
- Автоматическое извлечение заголовков

## 📊 Новые возможности

### **Команды для администраторов:**

1. **`/system_info`** - Показывает:
   - Используемые модели
   - Количество документов
   - Активные настройки
   - Состояние векторного хранилища

2. **`/load_advanced`** - Загрузка с:
   - Семантическим чанкингом
   - Извлечением метаданных
   - Автоматической оптимизацией

3. **`/load_standard`** - Стандартная загрузка:
   - Фиксированный размер чанков (512)
   - Базовые метаданные
   - Совместимость с существующими документами

### **Улучшенный поиск:**
- Автоматическое создание 2-3 вариантов запроса
- Выбор лучшего результата по оценке качества
- Адаптивные параметры в зависимости от запроса

## 🔍 Как это работает

### **Обычный поиск:**
1. Пользователь задает вопрос
2. Система создает вариации запроса
3. Выполняется поиск по каждой вариации
4. Выбирается лучший результат
5. Добавляется информация из интернета (если включено)

### **Загрузка документов:**
1. **Семантическая обработка** (если включена):
   - Анализ смысла текста
   - Разбивка по семантическим блокам
   - Извлечение заголовков и ключевых вопросов

2. **Стандартная обработка**:
   - Фиксированные чанки по 512 токенов
   - 10% перекрытия между чанками
   - Базовые метаданные
