# Настройка DeepSeek для замены OpenAI

Этот проект был обновлен для использования бесплатной модели DeepSeek вместо OpenAI.

## Что изменилось

1. **Добавлен Docker контейнер с DeepSeek**: Используется Ollama для запуска модели DeepSeek R1 (8B параметров)
2. **Создан адаптер DeepSeek**: Обеспечивает совместимость с API OpenAI
3. **Обновлена конфигурация**: Добавлены настройки для переключения между OpenAI и DeepSeek

## Настройка окружения

Создайте файл `.env` на основе примера и настройте следующие переменные:

```bash
# Для использования DeepSeek
USE_DEEPSEEK=true
DEEPSEEK_BASE_URL=http://deepseek:11434
DEEPSEEK_MODEL=deepseek-r1:8b
DEEPSEEK_EMBED_MODEL=nomic-embed-text

# Для возврата к OpenAI (если нужно)
USE_DEEPSEEK=false
OPEN_AI_TOKEN=your_openai_token_here
```

## Запуск системы

1. **Соберите и запустите контейнеры**:
   ```bash
   docker-compose up --build
   ```

2. **Дождитесь загрузки моделей**: При первом запуске DeepSeek загрузит модели (это может занять некоторое время)

3. **Проверьте статус**: Убедитесь, что все сервисы запущены:
   ```bash
   docker-compose ps
   ```

## Преимущества DeepSeek

- ✅ **Бесплатно**: Полностью бесплатная альтернатива OpenAI
- ✅ **Локально**: Работает на ваших серверах, данные не передаются третьим лицам
- ✅ **Производительность**: DeepSeek R1 показывает результаты, сравнимые с GPT-4
- ✅ **Совместимость**: Полная совместимость с существующим кодом

## Системные требования

- **RAM**: Минимум 8 ГБ (рекомендуется 16 ГБ)
- **Диск**: ~10 ГБ свободного места для моделей
- **GPU**: Опционально (ускорит работу, но не обязательно)

## Мониторинг

- **DeepSeek API**: http://localhost:11434
- **Проверка моделей**: `curl http://localhost:11434/api/tags`
- **Логи**: `docker-compose logs deepseek`

## Возврат к OpenAI

Если нужно вернуться к OpenAI, измените в `.env`:
```bash
USE_DEEPSEEK=false
OPEN_AI_TOKEN=your_actual_token
```

И перезапустите приложение:
```bash
docker-compose restart openaiapp
```

## Устранение неполадок

1. **Модели не загружаются**: Проверьте логи `docker-compose logs deepseek`
2. **Медленная работа**: Увеличьте RAM или добавьте GPU
3. **Ошибки подключения**: Убедитесь, что контейнер deepseek запущен и здоров

## Поддержка

Если возникли проблемы с DeepSeek, проверьте:
- Статус контейнеров: `docker-compose ps`
- Логи DeepSeek: `docker-compose logs deepseek`
- Доступность API: `curl http://localhost:11434/api/tags`
